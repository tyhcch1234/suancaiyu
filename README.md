# 酸菜魚 · 一鍋酸香，魚片滑如絹

一個關於酸菜魚的單頁網站：歷史與產地、六步做法（附影片）、常見失手位，以及 9 題互動測驗。

- 純靜態：`index.html` + `assets/`，無後端、無追蹤
- 內容：重慶江津起源的兩個傳說、鄒開喜的改良、江湖菜脈絡、2015 年太二酸菜魚的連鎖化
- 做法：片魚 → 上漿 → 炒酸菜 → 熬湯 → 汆魚片 → 淋油
- 測驗：即時對錯、逐題解說、成績環與等級評語

## 本地開啟

```
python3 -m http.server 8000
```

然後開 http://localhost:8000
